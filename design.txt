ANTIGRAVITY MASTER PROMPT — UEBA V2.1 SOC COMMAND CENTER REDESIGN

You are redesigning the existing UEBA V2.1 frontend into a professional, highly interactive Security Operations Center (SOC) / User and Entity Behavior Analytics investigation console.

The current frontend is functional but visually resembles a generic CRUD/admin dashboard. Do NOT simply polish the existing cards and tables. Re-architect the frontend information hierarchy and interaction model.

The attached reference image is the visual inspiration.

The goal is:

“A real SOC analyst workstation for investigating behavioral anomalies, attack chains and investigation cases.”

It must look like a serious cybersecurity analytics product—not a template, SaaS landing page, AI-generated dashboard, or collection of decorative cards.
IMPORTANT ARCHITECTURAL CORRECTION

Do NOT blindly implement the previous plan's assumption that Attack Chains,
Investigations, Welford, CTMC, or Rule Engine are UNAVAILABLE.

The backend V2.1 verification establishes that these components exist and are
implemented:

what is visible.
